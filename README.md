## STEP 2. Quiz 클래스 구현

### 목표

하나의 퀴즈 문제를 표현할 수 있는 `Quiz` 클래스를 구현한다.

### 2-1. 클래스란?

클래스(Class)는 객체를 만들기 위한 설계도이다.

예를 들어 퀴즈 문제에는 다음과 같은 정보가 필요하다.

- 질문 내용
- 선택지
- 정답

이러한 정보들을 하나의 구조로 묶어 관리하기 위해 클래스를 사용한다.

클래스가 설계도라면 객체(Object)는 그 설계도를 바탕으로 실제 만들어진 결과물이라고 이해하면 된다.

예를 들어 `Quiz` 클래스가 퀴즈를 만드는 설계도라면, 제주도의 위치를 묻는 문제 하나하나가 객체가 된다.

### 2-2. 생성자 `__init__`

생성자는 객체가 만들어질 때 자동으로 실행되는 특별한 메서드이다.

Python에서는 `__init__()`을 사용한다.

```python
class Quiz:
    def __init__(self, question, choices, answer):
        self.question = question
        self.choices = choices
        self.answer = answer
```

각 부분의 역할은 다음과 같다.

| 코드 | 역할 |
|---|---|
| `class Quiz:` | Quiz 클래스 정의 |
| `__init__()` | 객체 생성 시 자동 실행되는 생성자 |
| `question` | 문제 내용 |
| `choices` | 선택지 목록 |
| `answer` | 정답 |
| `self` | 현재 생성되거나 사용되는 객체 자신 |

### 2-3. `self`의 역할

`self`는 현재 객체 자신을 가리킨다.

예를 들어 다음과 같은 객체를 생성한다고 가정한다.

```python
quiz1 = Quiz(
    "대한민국의 수도는?",
    ["서울", "부산", "대구", "광주"],
    1
)
```

이때 생성자의 `self.question`에는 `"대한민국의 수도는?"`이 저장된다.

`self.choices`에는 선택지 목록이 저장되고, `self.answer`에는 정답이 저장된다.

`self`는 지금 만들어지고 있는 객체를 가리킨다.
이렇게 `self`를 사용하면 각 객체가 자신의 데이터를 독립적으로 보관할 수 있다.

### 2-4. 객체 생성 및 확인

클래스 아래에 다음 코드를 추가하여 객체를 생성해 본다.

```python
quiz1 = Quiz(
    "대한민국의 수도는?",
    ["서울", "부산", "대구", "광주"],
    1
)

print(quiz1.question)
print(quiz1.choices)
print(quiz1.answer)
```

실행 결과:

```text
대한민국의 수도는?
['서울', '부산', '대구', '광주']
1
```

## STEP 3. 기본 퀴즈 데이터 등록

### 목표

프로그램을 실행했을 때 사용할 기본 퀴즈 5개를 등록한다.

### 3-1. 리스트(List)란?

리스트는 여러 개의 데이터를 하나의 변수에 저장할 수 있는 자료형이다.

예를 들어 다음과 같이 작성할 수 있다.

```python
numbers = [10, 20, 30, 40]
```

리스트는 여러 개의 퀴즈 객체를 저장할 때 유용하다.

### 3-2. 기본 퀴즈 등록

`Quiz` 클래스를 활용하여 여러 개의 퀴즈 객체를 생성한다.

```python
quizzes = [
    Quiz(
        "대한민국의 수도는?",
        ["서울", "부산", "대구", "광주"],
        1
    ),
    Quiz(
        "대한민국에서 가장 넓은 광역시는?",
        ["대전", "광주", "부산", "울산"],
        3
    ),
    Quiz(
        "제주특별자치도의 중심 도시는?",
        ["서귀포", "제주시", "목포", "여수"],
        2
    ),
    Quiz(
        "대한민국의 동쪽에 위치한 대표적인 광역시는?",
        ["인천", "광주", "울산", "대전"],
        3
    ),
    Quiz(
        "전라남도의 도청 소재지는?",
        ["순천", "목포", "여수", "무안"],
        4
    )
]
```

이때 정답 번호는 1번부터 시작하도록 작성했다.

Python 리스트의 인덱스는 0부터 시작하지만, 사용자에게는 1번부터 선택지를 보여주기 위해 정답 번호를 별도로 관리한다.

### 3-3. 반복문을 활용한 데이터 확인

`for` 반복문을 사용하면 리스트에 저장된 데이터를 하나씩 확인할 수 있다.

```python
for quiz in quizzes:
    print(quiz.question)
    print(quiz.choices)
```

## STEP 4. QuizGame 클래스 및 메인 메뉴 구현

### 목표

전체 게임을 관리하는 `QuizGame` 클래스를 만들고 메인 메뉴를 구현한다.

### 4-1. QuizGame 클래스가 필요한 이유

앞에서 만든 `Quiz` 클래스는 개별 문제의 정보를 관리한다.

하지만 전체 프로그램에는 문제를 출제하고, 점수를 계산하고, 문제를 추가하는 등 여러 기능이 필요하다.

이러한 기능을 한곳에서 관리하기 위해 `QuizGame` 클래스를 만든다.

```python
class QuizGame:
    def __init__(self, quizzes):
        self.quizzes = quizzes
        self.high_score = 0
```

`self.quizzes`는 전체 퀴즈 목록을 저장하고, `self.high_score`는 최고 점수를 저장한다.

### 4-2. 메인 메뉴 구현

```python
def show_menu(self):
    print("\n====================================")
    print("       한국 지명 맞추기 퀴즈")
    print("====================================")
    print("1. 퀴즈 풀기")
    print("2. 퀴즈 추가")
    print("3. 퀴즈 목록 확인")
    print("4. 최고 점수 확인")
    print("5. 프로그램 종료")
```

메뉴를 출력하는 기능을 별도의 메서드로 분리했다.

### 4-3. 반복문을 활용한 메뉴 실행

메인 메뉴는 프로그램이 종료될 때까지 반복되어야 한다.

이때 `while` 반복문을 사용할 수 있다.

```python
def run(self):
    while True:
        self.show_menu()

        choice = input("메뉴를 선택하세요: ")

        if choice == "1":
            print("퀴즈 풀기")
        elif choice == "2":
            print("퀴즈 추가")
        elif choice == "3":
            print("퀴즈 목록 확인")
        elif choice == "4":
            print("최고 점수 확인")
        elif choice == "5":
            print("프로그램을 종료합니다.")
            break
        else:
            print("올바른 메뉴 번호를 입력하세요.")
```

### `while`과 `for`의 차이

- `for`: 리스트의 요소를 하나씩 처리하거나 정해진 횟수만큼 반복할 때 사용한다.
- `while`: 특정 조건이 유지되는 동안 반복할 때 사용한다.

메뉴는 사용자가 종료를 선택할 때까지 계속 실행되어야 하므로 `while`을 사용하는 것이 적절하다.

### 5-1. 함수와 메서드

함수(Function)는 특정 작업을 수행하는 코드의 묶음이다.

클래스 내부에 정의된 함수는 메서드(Method)라고 부른다.

예를 들어 다음 코드는 퀴즈를 실행하는 메서드이다.

```python
def play_quiz(self):
    score = 0

    for quiz in self.quizzes:
        print("\n" + quiz.question)

        for i, choice in enumerate(quiz.choices, start=1):
            print(f"{i}. {choice}")

        answer = input("정답을 입력하세요: ")

        if answer == str(quiz.answer):
            print("정답입니다!")
            score += 1
        else:
            print("오답입니다.")

    print(f"최종 점수: {score} / {len(self.quizzes)}")
```

### 5-2. 매개변수와 반환값

매개변수는 함수에 전달하는 값이다.

반환값은 함수가 작업을 수행한 후 결과로 돌려주는 값이다.

예를 들어 다음과 같은 함수가 있다.

```python
def add(a, b):
    return a + b
```

`a`와 `b`는 매개변수이고, `return`은 계산 결과를 반환한다.

퀴즈 기능에서도 최종 점수를 반환하도록 만들 수 있다.

```python
def play_quiz(self):

    return score
```

### 5-3. 점수 계산 및 최고 점수 갱신

```python
score = self.play_quiz()
```

### 5-4. enumerate()

```python
choices = ["서울", "부산", "대구", "광주"]
```

### 6-1. input()

`input()`은 사용자로부터 입력을 받는 함수이다.

```python
name = input("이름을 입력하세요: ")
```

입력된 값은 기본적으로 문자열(str)로 저장된다.

### 6-2. 퀴즈 추가 메서드

사용자가 문제 내용, 선택지 4개, 정답 번호를 입력하도록 한다.

```python
def add_quiz(self):
    question = input("문제를 입력하세요: ")

    choices = []

    for i in range(4):
        choice = input(f"{i + 1}번 선택지: ")
        choices.append(choice)

    answer = int(input("정답 번호(1~4): "))

    quiz = Quiz(question, choices, answer)

    self.quizzes.append(quiz)

    print("퀴즈가 추가되었습니다.")
```

### 6-3. append()


## STEP 9. JSON 파일 저장 및 불러오기

### 목표

기본적인 퀴즈 프로그램은 모두 완성했다.
이제 프로그램을 종료하더라도 퀴즈와 최고 점수가 사라지지 않도록 파일에 저장하는 기능을 구현하겠다.

### 9-1. 파일 입출력이란?

파일 입출력(File I/O)은 프로그램에서 파일을 읽거나 쓰는 작업이다.

지금까지 구현한 프로그램은 실행 중에만 데이터를 유지한다.

프로그램을 종료하면 메모리에 저장된 데이터가 사라진다.

이를 해결하기 위해 파일에 데이터를 저장한다.

### 9-2. JSON이란?

JSON(JavaScript Object Notation)은 데이터를 저장하고 교환하기 위한 형식이다.

사람이 읽기 쉽고 Python에서도 간편하게 사용할 수 있다.

예를 들어 다음과 같이 데이터를 저장할 수 있다.

```json
{
    "quizzes": [
        {
            "question": "대한민국의 수도는?",
            "choices": ["서울", "부산", "대구", "광주"],
            "answer": 1
        }
    ],
    "high_score": 1
}
```

JSON에서는 다음과 같은 자료형을 사용할 수 있다.

| JSON 자료형 | Python 자료형 |
|---|---|
| object | dict |
| array | list |
| string | str |
| number | int, float |
| true / false | True / False |
| null | None |

### 9-3. json 모듈

Python에서는 `json` 모듈을 사용하여 JSON 데이터를 저장하고 불러올 수 있다.

파일 상단에 다음 코드를 추가한다.

```python
import json
```

### 9-4. 데이터 저장

먼저 퀴즈 객체를 JSON으로 저장할 수 있는 형태로 변환해야 한다.

```python
def save_data(self):
    data = {
        "quizzes": [
            {
                "question": quiz.question,
                "choices": quiz.choices,
                "answer": quiz.answer
            }
            for quiz in self.quizzes
        ],
        "high_score": self.high_score
    }

    with open("state.json", "w", encoding="utf-8") as file:
        json.dump(data, file, ensure_ascii=False, indent=4)
```

### 코드 설명

**딕셔너리(dict)**

딕셔너리는 키(key)와 값(value)을 한 쌍으로 저장하는 자료형이다.

```python
person = {
    "name": "홍길동",
    "age": 20
}
```

`"name"`은 키이고 `"홍길동"`은 값이다.

JSON 데이터도 이러한 구조를 활용하여 저장한다.

**with open()**

```python
with open("state.json", "w", encoding="utf-8") as file:
```

- `open()`: 파일을 연다.
- `"state.json"`: 파일 이름이다.
- `"w"`: 파일에 새 내용을 작성한다.
- `encoding="utf-8"`: 한글이 깨지지 않도록 UTF-8 인코딩을 사용한다.
- `with`: 작업이 끝나면 파일을 자동으로 닫아준다.

**json.dump()**

Python 데이터를 JSON 파일에 저장하는 함수이다.

- `ensure_ascii=False`: 한글을 유니코드 이스케이프 형태가 아닌 읽을 수 있는 문자로 저장한다.
- `indent=4`: 들여쓰기를 4칸으로 지정하여 가독성을 높인다.

### 9-5. 데이터 불러오기

저장한 JSON 파일을 다시 읽어 객체로 변환해야 한다.

```python
def load_data(self):
    try:
        with open("state.json", "r", encoding="utf-8") as file:
            data = json.load(file)

        self.quizzes = [
            Quiz(
                item["question"],
                item["choices"],
                item["answer"]
            )
            for item in data["quizzes"]
        ]

        self.high_score = data["high_score"]

    except FileNotFoundError:
        print("저장된 데이터가 없습니다. 기본 데이터를 사용합니다.")

    except json.JSONDecodeError:
        print("저장 파일이 손상되었습니다. 기본 데이터를 사용합니다.")
```

`json.load()`는 JSON 파일의 내용을 읽어 Python 자료형으로 변환한다.

저장된 딕셔너리의 데이터를 이용해 `Quiz` 객체를 다시 생성한다.

### 9-6. 저장과 불러오기 시점

프로그램을 실행할 때 데이터를 불러오고, 데이터를 변경할 때 저장하도록 구성한다.

예를 들어 퀴즈 추가 후에는 다음과 같이 호출할 수 있다.

```python
self.quizzes.append(quiz)
self.save_data()
```

퀴즈를 풀어 최고 점수가 갱신된 경우에도 저장한다.

프로그램을 처음 실행할 때는 기본 퀴즈를 준비한 후 저장 파일이 있는지 확인하는 순서를 설계해야 한다.

저장 파일이 없으면 기본 데이터를 사용하고, 저장 파일이 있으면 저장된 데이터를 불러오도록 구성한다.

## STEP 10. 사용자 입력 검증 및 예외 처리

### 목표

사용자가 잘못된 값을 입력하거나 예상하지 못한 상황이 발생해도 프로그램이 비정상적으로 종료되지 않도록 한다.

### 10-1. 예외란?

예외(Exception)는 프로그램 실행 중 발생하는 오류 상황이다.

예를 들어 숫자를 입력받는 상황에서 사용자가 문자를 입력하면 문제가 발생할 수 있다.

```python
number = int(input("숫자를 입력하세요: "))
```

사용자가 `hello`를 입력하면 문자열을 정수로 변환할 수 없기 때문에 `ValueError`가 발생한다.

### 10-2. try와 except

Python에서는 `try`와 `except`를 사용하여 예외를 처리할 수 있다.

```python
try:
    number = int(input("숫자를 입력하세요: "))
    print(number)

except ValueError:
    print("숫자만 입력해주세요.")
```

`try` 안의 코드에서 예외가 발생하면 해당 예외에 맞는 `except`가 실행된다.

### 10-3. 퀴즈 정답 입력 검증

정답을 입력받을 때 숫자인지 확인하고, 선택지 범위 안에 있는지도 검사한다.

```python
while True:
    answer = input("정답 번호를 입력하세요: ")

    if answer.isdigit():
        answer = int(answer)

        if 1 <= answer <= 4:
            break

    print("1부터 4 사이의 숫자를 입력해주세요.")
```

`isdigit()`은 문자열이 숫자로만 구성되어 있는지 확인하는 메서드이다.

### 10-4. 빈 문자열 검사

사용자가 아무것도 입력하지 않는 경우도 처리해야 한다.

```python
question = input("문제를 입력하세요: ").strip()

if not question:
    print("문제 내용을 입력해주세요.")
```

`strip()`은 문자열의 양쪽 공백을 제거한다.

### 10-5. 추가로 고려할 예외

| 예외 | 발생 상황 | 처리 방향 |
|---|---|---|
| `ValueError` | 잘못된 숫자 변환 | 다시 입력하도록 안내 |
| `FileNotFoundError` | 저장 파일이 존재하지 않음 | 기본 데이터 사용 |
| `json.JSONDecodeError` | JSON 파일 형식이 잘못됨 | 오류 안내 및 기본 데이터 사용 |
| `EOFError` | 입력이 더 이상 제공되지 않음 | 프로그램 종료 처리 |
| `KeyboardInterrupt` | 사용자가 Ctrl+C를 누름 | 안전하게 종료 |

`EOFError`와 `KeyboardInterrupt`는 일반적인 메뉴 입력을 포함한 프로그램 실행 흐름에서 발생할 수 있으므로, 최상위 실행 부분에서 처리하는 것이 좋다.

예를 들어 다음과 같이 구성할 수 있다.

```python
if __name__ == "__main__":
    try:
        game = QuizGame(quizzes)
        game.load_data()
        game.run()

    except (EOFError, KeyboardInterrupt):
        print("\n프로그램을 종료합니다.")
```

이 코드는 사용자가 입력을 중단하거나 Ctrl+C를 누른 경우 프로그램이 종료되도록 한다.

### 테스트 방법

- 메뉴에 문자를 입력한다.
- 숫자가 아닌 값을 정답으로 입력한다.
- 선택지 범위를 벗어난 번호를 입력한다.

## STEP 13. 랜덤 퀴즈 출제

### 목표

문제가 항상 같은 순서로 출제되는 것이 아니라 무작위 순서로 출제되도록 한다.

### 13-1. random 모듈

`random` 모듈은 무작위 값을 생성하는 기능을 제공한다.

```python
import random
```

### 13-2. random.sample()

`random.sample()`은 리스트에서 지정한 개수만큼 중복 없이 무작위로 선택한다.

```python
selected_quizzes = random.sample(self.quizzes, len(self.quizzes))
```

이렇게 하면 원본 퀴즈 목록을 변경하지 않고 출제 순서만 무작위로 만들 수 있다.

문제 수 선택 기능과 결합할 경우 다음과 같이 사용할 수도 있다.

```python
selected_quizzes = random.sample(self.quizzes, count)
```

### 테스트 방법

- 원본 퀴즈 목록이 변경되지 않는지 확인한다.
- 등록된 문제 수보다 많이 선택하지 않도록 처리한다.

## STEP 15. 힌트 기능 추가

### 목표

사용자가 문제를 풀다가 어려움을 느끼면 힌트를 확인할 수 있도록 한다.

### 15-1. Quiz 클래스 수정

기존 `Quiz` 클래스에 `hint` 속성을 추가한다.

```python
class Quiz:
    def __init__(self, question, choices, answer, hint=""):
        self.question = question
        self.choices = choices
        self.answer = answer
        self.hint = hint
```

기본값을 빈 문자열로 지정했기 때문에 힌트를 입력하지 않아도 객체를 생성할 수 있다.

### 15-2. 힌트 출력

퀴즈를 풀 때 특정 입력을 받으면 힌트를 보여주도록 구현한다.

```python
if answer == "h":
    print(f"힌트: {quiz.hint}")
```

힌트를 확인한 후 다시 정답을 입력할 수 있도록 반복문을 구성해야 한다.

### 15-3. JSON 저장 구조 수정

새로운 `hint` 속성이 추가되었으므로 JSON 저장 및 불러오기 코드에도 반영해야 한다.

저장 예시:

```python
{
    "question": "대한민국의 수도는?",
    "choices": ["서울", "부산", "대구", "광주"],
    "answer": 1,
    "hint": "대한민국의 정치와 행정의 중심지"
}
```

기존 `state.json`에는 `hint`가 없을 수 있으므로 불러올 때 다음과 같이 기본값을 지정하는 것이 안전하다.

```python
item.get("hint", "")
```

### 테스트 방법

- 힌트가 있는 문제에서 힌트가 출력되는가?
- 힌트를 확인한 후에도 정답을 입력할 수 있는가?

## STEP 16. 퀴즈 삭제 기능 추가

### 목표

사용자가 등록한 퀴즈를 삭제할 수 있도록 한다.

### 16-1. 리스트의 요소 삭제

Python에서는 `pop()`이나 `remove()`를 사용하여 리스트의 요소를 삭제할 수 있다.

```python
numbers = [10, 20, 30]

numbers.pop(1)

print(numbers)
```

실행 결과:

```text
[10, 30]
```

`pop()`은 지정한 인덱스의 요소를 삭제하고 그 값을 반환한다.

### 16-2. 퀴즈 삭제 구현

먼저 현재 등록된 퀴즈 목록을 출력하고 삭제할 번호를 입력받는다.

```python
def delete_quiz(self):
    self.show_quizzes()

    number = int(input("삭제할 퀴즈 번호를 입력하세요: "))

    if 1 <= number <= len(self.quizzes):
        self.quizzes.pop(number - 1)
        self.save_data()
        print("퀴즈가 삭제되었습니다.")
    else:
        print("올바른 번호를 입력해주세요.")
```

사용자에게는 1번부터 번호를 보여주지만 리스트의 인덱스는 0부터 시작한다.

따라서 `number - 1`을 사용한다.

### 16-3. 삭제 정책

삭제 기능을 구현할 때는 기본 퀴즈와 사용자가 추가한 퀴즈를 모두 삭제할 것인지 결정해야 한다.

간단한 구현에서는 모든 퀴즈를 동일하게 관리할 수 있다.

다만 기본 문제를 보호하고 싶다면 퀴즈 객체에 별도의 구분 정보를 추가하는 방법도 있다.

## STEP 17. 점수 기록 히스토리 추가

### 목표

최고 점수뿐만 아니라 사용자가 퀴즈를 풀었던 기록도 저장하도록 한다.

### 17-1. 리스트를 활용한 기록 관리

점수 기록은 여러 개가 필요하므로 리스트로 관리할 수 있다.

예를 들어 다음과 같은 구조를 사용할 수 있다.

```python
score_history = [
    {
        "score": 3,
        "total": 5
    },
    {
        "score": 5,
        "total": 5
    }
]
```

### 17-2. 점수 기록 추가

퀴즈가 끝나면 점수 기록을 추가한다.

```python
self.score_history.append({
    "score": score,
    "total": total
})
```

### 17-3. JSON 저장 구조 통합

최종적으로 JSON 파일은 다음과 같은 구조로 관리할 수 있다.

```json
{
    "quizzes": [],
    "high_score": 0,
    "score_history": []
}
```

기존의 퀴즈와 최고 점수 정보에 `score_history`를 추가한다.

데이터를 불러올 때도 해당 항목을 반영해야 한다.

```python
self.score_history = data.get("score_history", [])
```

`get()`을 사용하면 해당 키가 존재하지 않는 경우 기본값을 반환한다.

### 17-4. 점수 기록 확인

기록 목록을 반복문으로 출력하면 사용자가 이전 점수를 확인할 수 있다.

```python
def show_score_history(self):
    print("\n===== 점수 기록 =====")

    for i, record in enumerate(self.score_history, start=1):
        print(
            f"{i}회차: "
            f"{record['score']} / {record['total']}"
        )
```
